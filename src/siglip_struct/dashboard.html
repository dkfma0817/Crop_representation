05 / SCALE

작은 ROI에서 격차가 더 큰가

384 canvas의 GT bbox 면적 기준: tiny <32², small 32²–64², medium 64²–128², large ≥128². 구간별 category 구성과 positive 수가 다르므로 크기의 인과 효과로 해석하지 않습니다.

07 / EFFICIENCY

성능 개선에 얼마를 지불하는가

P4는 저장 feature와 연산이 증가하지만 4px patch kernel은 작아 parameter 수는 오히려 줄 수 있습니다. Decoder는 별도 학습된 약11.26M parameter를 추가합니다. R2는 조건별 약10.74M parameter로 동일합니다. C0는 ROI마다 RGB crop을 재인코딩하므로 full-image 1회 비용과 단위를 섞지 않습니다.

2 FLOPs/MAC, dense/conv/attention 연산 기준이며 normalization·activation·softmax·token 선택은 제외합니다. 지연시간은 같은 실행에서 측정했더라도 표본 image와 batch의 영향을 받습니다. 추가 계산량을 통제한 인과 비교는 아닙니다.

08 / READING THIS REPORT

비교와 해석의 경계

유지한 조건

  • RGB 입력384×384, seed0, 동일한 공식 SigLIP2 Vision backbone.
  • P4: 공식 pretrained coarse + 새 Fine, COCO12k, 기존 mean cosine/global preservation.
  • Native/Decoder: 완료 P12k EMA 고정. Decoder는 COCO만 사용해 mean cosine12k.
  • 독립 R2, 같은10epochs·학습 split·flip·optimizer·schedule.
  • 공식 VAL Object/Part 평균으로 best epoch 선택, 동률이면 이른 epoch. TEST는 선택 이후 평가.
  • 기존 P8/M/FullB0/C0 결과와 checkpoint를 보존.

단정하지 않는 것

  • 높은 teacher cosine = 높은 attribute AP.
  • 576개 ROIAlign 위치 = 576개의 독립적인 실제 관측.
  • P4의 변화 = fine granularity만의 인과 효과.
  • Decoder 개선 = 추가 capacity와 COCO 학습량과 무관한 순수 ROI 정제 효과.
  • C0는 모든 속성에서 우수하거나 성능의 수학적 상한이라는 주장.
  • G1을 사용했던 DINOv3와 G1 없는 SigLIP2의 절대 AP를 backbone 효과로 해석.
세부 구현 차이와 명칭

이 보고서의 Full B0는 frozen SigLIP2 full-image baseline입니다. 새 구조 실험에서 B0라고 요청한 Native Token Selection은 혼동을 피하려고 Native로 표기합니다. Native fine384는 기존 frozen Wd로768에 매핑하며 independent key에는 fused-map scalar s_d를 적용하지 않습니다. Type은 native stride16/8의 geometry와 metadata에 보존합니다. P4의 fine sinusoidal position은 동일한 token-index 공식을96-grid에서 사용합니다.

이전 G1-cross 대비 이번 Decoder는 frozen 학습완료 P12k, coarse+fine native keys,16queries,MLPx2,ROI+25% context,mean-only 감독입니다. Query 위치는 상대xy·절대xy·GT box4의8개 값 → MLP + learned grid로 인코딩하며, 이전 Fourier query encoding과도 다릅니다. 이전의 joint encoder/decoder,coarse-only576queries,MLPx4,전체-image 문맥 및 token/detail 감독과 다르며 이전 checkpoint를 쓰지 않습니다.

이전 E1/E2/Continue는 별도4k phase 결과이며 처음부터16k 학습한 모델이 아닙니다. 구조 실험에는 새 loss를 추가하지 않았습니다. Mean Probe가 없는 새 조건의 값은 추정하지 않습니다.
