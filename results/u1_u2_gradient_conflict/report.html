1. Research Question

P2는 B0 대비 ADE20K를 2.079pp 회복했고, Original 대비 -2.460pp의 격차가 남았습니다. 이번에는 P2의 동일 Loss·Teacher·Architecture에서 Crop Gradient 결합 규칙을 바꾼 U1과 U2를 비교합니다.

2. Method & Verification

g_P2 = gc + 0.5 gg + λ gp
gc_proj = gc − min(0, gc·gp / ||gp||²) gp
g_U1 = gc_proj + 0.5 gg + λ gp = gc + 0.5 gg + λ_eff gp
λ_eff = λ + max(0, −gc·gp / ||gp||²)
rho = ||gc_proj|| / (||gc|| + ε)
g_U2 = rho gc + 0.5 gg + λ gp

λ=0.065171371165. ||gp|| ≤ 1e-07 또는 ||gc|| ≤ 1e-12일 때 Projection을 건너뜁니다. 충돌이 없으면 rho=1, λ_eff=λ입니다. Encoder 전체를 고정된 Parameter Ordering의 한 벡터로 취급합니다. 세 Loss의 Gradient를 같은 배치에서 각각 계산하고 FP32, unscaled 상태로 결합합니다. 계수 계산은 Autograd Graph 밖에서 수행합니다.

두 실험은 각각 world1, Accumulation1이며 동일16-image 전역 Stream과 기존 제외 정책을 사용합니다. Rank별 Local Projection이나 All-reduce는 없습니다. BF16 Forward, FP32 파라미터·Gradient, AdamW,600-step Warmup+Cosine, LLRD0.75, WD0.05, Clip1, EMA를 P2와 맞췄습니다. 독립 Original 초기화에서 12k 학습하고 Final EMA를 평가합니다.

U1은 PCGrad 계열의 비대칭 변형이며 Gradient 수준에서 Adaptive Preservation Weighting과 같습니다. U2는 Projected Crop Gradient의 Norm을 맞추는 대조군입니다. 합성 Gradient Norm과 AdamW 실제 Parameter Update Norm은 맞추지 않습니다. Momentum과 Weight Decay도 실제 Update에 영향을 줍니다.

FP32 Gradient 합산과 Projection 식의 Unit Test, U2 Norm Matching, 충돌 없음, Zero/Tiny Preservation, Non-finite 거부, Patch Embedding·12block·최종 Norm Gradient를 검증했습니다. 실제 BF16 경로의 분리 VJP 합산은 Total Loss 단일 VJP와 반올림 차이가 있어, 사전 고정한 상대 L2 2% 기준과 실제 측정값을 아래 표에 기록합니다. 정규화 오류 확인용 전체 FP32 기준 계산은 TF32와 Fused Attention을 끈 Math Reference를 사용합니다. 학습은 P2의 BF16 경로를 사용합니다.
