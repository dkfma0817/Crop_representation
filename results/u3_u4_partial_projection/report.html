2. Method & Verification

g_P2 = gc + 0.5 gg + lambda gp
gc_partial = gc - alpha min(0, gc·gp / ||gp||²) gp
g_Ualpha = gc_partial + 0.5 gg + lambda gp
lambda_eff = lambda + alpha max(0, -gc·gp / ||gp||²)
g_Ualpha = gc + 0.5 gg + lambda_eff gp

lambda=0.06517137116455. U3 alpha=0.25, U4 alpha=0.50은 사전 고정입니다. 기존 U1 함수를 수정하지 않고 전체 투영 결과와 gc 사이를 FP32에서 보간합니다. Encoder 전체 Parameter를 고정 순서의 한 벡터로 취급합니다. ||gp||≤1e-7 또는 ||gc||≤1e-12이면 건너뜁니다. 계수는 no_grad 상수입니다.

이 Update는 Adaptive Preservation Weighting과 동등하며 독창적인 알고리즘 또는 엄밀한 Safe Update로 주장하지 않습니다. Global/Preservation Gradient는 변경하지 않습니다. AdamW Momentum·Weight Decay와 Gradient Clip1도 실제 Parameter Update에 영향을 줍니다.

Endpoint alpha0=P2, alpha1=U1은 같은 입력 Gradient에서 Bit Equality로 검증했습니다. 고정 alpha의 직접식·Adaptive Lambda 동등성, Non-conflict, Zero/Tiny, Non-finite 거부를 검증했습니다. 실제 Original/P2 Encoder의 동일 COCO Batch에서도 검사했습니다.

6. PACO–ADE20K Trade-off

Overall-ADE Frontier: P2, U1, U2. 표의 실제 값을 반올림하기 전 비교한 산술적 Frontier이며, 통계적 우월성이나 모든 Attribute의 개선을 뜻하지 않습니다. 손실 강도·Feature Drift 변화는 Gradient Table과 함께 판단합니다.

7. Conclusion & Reproducibility

관측된 결과

두 조건의 학습·공식 평가를 진행 중입니다. 측정되지 않은 수치는 비워 두며, PACO 점수와 무관하게 ADE20K를 모두 수행합니다.

모든 PACO/ADE 평가가 완료된 뒤 Intermediate Trade-off와 Pareto 비교를 판단합니다.

해석과 남은 가설

유효한 중간 균형점의 근거는 PACO 판별력과 ADE가 함께 유지·개선되는 실제 비교입니다. ADE만 오르고 Pattern이 떨어지면 Preservation–Adaptation Trade-off입니다. Feature Drift 감소만으로 Semantic Information 보존을 입증하지 않습니다. 유리한 점이 보이더라도 추가 Seed에서의 재현과 클래스·경계별 오류 검증이 필요합니다. 추가 alpha, Loss 또는 Method 실험은 자동 실행하지 않습니다.
