ROI Sub-patch Predictor

Encoder는 모두 고정하고 predictor만 학습한다. Teacher는 같은 이미지를 보되 crop 영역만 아주 작은 token으로 잘라 넣는다. Student에게 그 촘촘한 token은 전부 가려져 있다. Student는 MAE·I-JEPA처럼 위치만 가진 mask token으로 그중 K개를 맞히고, 그 위치끼리 L1을 건다.

전체 구조

왼쪽이 context, 가운데가 student의 근거와 조건 z, 오른쪽이 target이다. 회색은 고정, 파란색은 학습한다.

네 색은 이미지의 네 구역이고, 점선 box는 그 경계에 걸친 random crop이다. 같은 box가 가운데에서는 고정 크기 근거 64개가 되고, 오른쪽에서는 teacher 입력 안에서 촘촘한 token으로 잘린다. 학습은 이미지 어디서나 뽑는 random crop으로 하고, PACO 평가 때만 GT box를 쓴다.

Dense teacher

crop을 잘라 384로 키우지 않는다. 같은 이미지를 고정 encoder에 한 번 넣되, crop 영역에만 더 작은 p_T px token을 넣는다. 출력에서 crop 영역 token을 꺼내 target T_crop으로 쓴다.

좋아지는 점

정렬이 정확하다

teacher token과 student query가 같은 이미지 좌표를 쓴다. resample, 면적 평균, letterbox, coverage 가중치가 모두 필요 없다.

좋아지는 점

맥락을 같이 본다

C0는 crop만 보지만, dense teacher는 crop 주변 이미지도 함께 본다. 맥락 없이 crop만 보는 것보다 좋은 target일 가능성이 있다.

여러 crop · masked teacher

forward 한 번에 crop 여러 개

16px token 576개는 서로만 본다. 그러면 이 부분은 student의 F와 똑같다. 각 촘촘한 영역은 16px token과 자기 영역만 본다. 그래서 한 forward로 crop 여러 개의 target을 얻고, 각 target은 같이 뽑힌 다른 crop과 무관하다.

1px token에서 걱정되는 점

  • token 하나가 pixel 하나, 즉 색 3개 값뿐이다. crop을 16배로 키워 평평한 색 블록으로 만든 뒤 16px로 자른 것과 같고, DINOv3가 본 적 없는 입력이다.
  • 배율이 crop 크기와 상관없이 16배로 고정된다. crop 크기에 따라 teacher token의 의미가 달라진다.
  • teacher는 gradient 없이 forward만 하지만 crop 전체를 돌려야 한다. crop 하나의 촘촘한 token을 최대 48×48로 제한하고, crop 크기는 48 · p_T px 이하로 뽑는다.

Masking과 위치

MAE와 I-JEPA의 mask token은 모두 같은 learnable 벡터 하나다. 무엇을 예측할지는 붙어 있는 위치 정보가 정한다. 우리도 같다. crop 영역을 p_T 해상도로 본 token 전체가 가려져 있고, student는 위치만 가진 mask token으로 그중 K개를 맞힌다.

1 · 좌표 통일

모든 token은 자기가 덮는 영역의 중심을 원본 이미지 좌표로 계산하고 [-1, 1]로 정규화한다. teacher token도 같은 함수로 계산한다. 그래야 query i와 teacher token i가 같은 점을 가리킨다.

2 · RoPE

2D 연속 좌표 RoPE를 attention마다 적용한다. query는 context와 근거만 보므로 "나와 가까운 context가 어디인지"가 가장 중요하고, RoPE가 그 상대 위치를 직접 표현한다.

3 · 크기

context 16px, 근거는 crop에 따라 다르고, query는 p_T px다. log(한 변 px / 16)을 MLP에 넣어 모든 token에 더한다.

query_i = m (공유 learnable) + E_size(log(p_T / 16)) + z_emb
q, k    = RoPE2D(q, k; x, y)    # 모든 token이 같은 좌표계
loss    = mean_{i ∈ K} | norm(Ŝ_i) − norm(T_crop,i) |

p_T = 8px이면 teacher token 위치가 근거 token 위치와 같아진다. 이때는 가린 것을 맞히는 문제가 아니라 보이는 pixel을 teacher처럼 다시 인코딩하는 문제가 된다. MAE·I-JEPA와 같은 의미의 masking이 되려면 p_T가 근거 크기보다 작아야 한다.

Token 예산

crop 영역은 z의 숫자 몇 개로 알려 주고, 예측할 위치는 독립 query로 필요한 만큼만 묻는다. 그래서 student sequence 길이는 crop 크기와 p_T에 상관없이 일정하다.

Attention mask

student의 mask는 target을 숨기지 않고, 정보가 흐르는 방향을 정한다. target은 predictor 입력에 들어가지 않으므로 누설될 길이 없다. 각 token은 자기 level과 그보다 아래 level만 보고, query는 다른 query를 보지 않는다.

1 · Level

위 level은 아래만 본다

context는 crop과 무관하게 이미지당 한 번, 근거는 query와 무관하게 crop당 한 번 계산된다. mask token이 근거 쪽으로 섞여 들어가지 않는다. V-JEPA 2-AC의 시간 축 block-causal mask를 level 축으로 옮긴 것이다.

2 · Query 독립

query는 자기 자신만

query끼리는 서로 보지 않는다. 그래서 학습 때 K개만 뽑아도 되고, 추론 때 아무 위치나 원하는 수만큼 물을 수 있다.

3 · Crop 분리

crop끼리는 서로 보지 않는다

이미지당 crop 여러 개를 한 sequence에 묶으면 context만 공유한다. 근거와 query 수가 고정이라 padding은 거의 필요 없다.

선택 · Context drop

crop 안 context 가리기

학습 때만 crop 안 F token을 확률 p로 지운다. 근거 pixel을 쓰도록 강제하는 ablation이다. 기본은 끈다.

z에는 무엇을 넣나

V-JEPA 2-AC에서 z는 "무엇을 예측할지"를 정하는 저차원 신호다. 위치는 RoPE가 맡으므로, z에는 crop 전체에 공통인 값만 넣는다.
